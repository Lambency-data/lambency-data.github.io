# Lambency

서울의 1인 데이터·AI 컨설팅 — 그로스·CRM 애널리틱스, 실험 설계, 프로덕션 LLM 에이전트.

---

## 구성

빌드 도구 없는 정적 사이트. HTML·CSS·바닐라 JS만 쓴다.

```
index.html            메인 (EN/KO 토글)
engagements.html      서비스·범위·가격
blog/index.html       Insights — 공개 데이터 시리즈 목록
blog/0N-*.html        개별 글
assets/               로고·파비콘·공유 이미지
robots.txt            검색엔진 크롤링 안내
sitemap.xml           색인용 URL 목록
```

로컬에서 보려면 `index.html` 을 브라우저로 열면 된다.

## Insights — 공개 데이터 시리즈

DART 감사보고서·공시·채용공고처럼 **누구나 열어볼 수 있는 자료만으로** 업종별 손익이 어디서 갈렸는지 분해한다. 내부 데이터는 쓰지 않는다.

원칙:
- **DART 원문에서 확인한 숫자만 쓴다.** 2차 집계·언론 요약은 헤드라인 숫자로 쓰지 않는다.
- **최신 사업연도부터 확인한다.** 비교는 같은 연도·같은 기준(별도/연결)으로 통일한다.
- **못 보는 것을 먼저 밝힌다.** 공개 자료로는 증분도, 채널별 기여이익도, 재구매도 확정할 수 없다.
- 발행 전 모든 수치를 원문으로 독립 재검증한다.

## 새 글 추가할 때

1. 기존 글 HTML을 복사해 본문만 교체 (CSS·헤더·푸터 동일)
2. `blog/index.html` 목록에 카드 추가
3. `sitemap.xml` 에 `<url>` 블록 추가
4. 새 글의 `og:url`·`canonical` 이 실제 주소인지 확인
